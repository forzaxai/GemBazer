Settings

How this admin panel works, and its limits.

No real backend — read this first

GemBazar is a static site. This admin panel is a local tool for drafting catalog changes and keeping a manual order log while you talk to customers directly — it is not connected to a database, and nothing here is saved once you close or refresh the tab.

To make catalog edits permanent, use Copy grid HTML on the Products tab and commit the result into index.html. For a shared, persistent order history across devices or teammates, you'd need a real backend (a small database, or a service like Airtable/Google Sheets behind a form) — happy to help wire one up if you want to go that route.

Passcode notice

The login screen is a basic deterrent, not real security — the passcode lives in this file's source code (search for ADMIN_PASSCODE), and anyone who views the page source on GitHub can read it. Don't use this panel to store anything genuinely sensitive, and if you need real access control, that also requires a proper backend with authentication.
